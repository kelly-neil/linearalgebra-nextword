## Instructions

Run either script from the project directory:
- `next_word_suggester_v1.py` runs the probability-matrix suggester in the terminal.
- `suggester_gui.py` opens the interactive suggester GUI.

Run either script with `python <filename>.py`.

You will also need one or more UTF-8 text corpus files in the project directory, named `corpus_<name>.txt`.
